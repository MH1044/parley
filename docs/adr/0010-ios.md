# ADR-0010: iOS: later

- **Status:** Proposed (the maintainer decides after module 13)
- **Date:** 2026-10-27

## Context

Tauri mobile can build for iOS as well as Android, but shipping on iOS needs an Apple developer
account for signing, the same account that signs and notarises the macOS build (module 14), a Mac
to build on, and App Store review. Android (module 13) needs none of that for a debug build and
reaches the learners on the platforms where Duolingo's energy limits bite hardest.

## Decision (proposed)

Recommended: iOS is not part of v1. Android is built in module 13; iOS is revisited once Android is
stable and the Apple developer account exists for macOS signing.

## Consequences

- No iOS-specific code or capability files in v1; the mobile layout is written for width, not
  platform, so an iOS build later reuses it.
- Learners on iPhones wait.
- The decision costs nothing to reverse later: the core and the interface are shared.

## Alternatives considered

- **iOS in v1**: an Apple developer account, a Mac in the build matrix and store review before the
  desktop app is stable. Rejected in the recommendation.
